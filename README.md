# 🛍️ AI Product Image Generator

An AI-powered product image generation system built for the 
NIAT Masterclass Kaggle Competition.

## 🚀 What it does
- Takes simple product descriptions as input
- Uses **Qwen 2.5 LLM** to engineer detailed image prompts
- Generates professional product images using **Stable Diffusion v1.5**
- Serves everything through a **Gradio web interface**

## 🏆 Results
- Prompt Quality Score : 28.8 / 40
- Image Quality Score  : 31.9 / 40
- Gradio UI Score      : 20.0 / 20 ✅
- **Total Score        : 80.7 / 100**
- Successfully ranked on Kaggle Leaderboard!

## 🔧 Tech Stack
| Tool | Purpose |
|------|---------|
| Qwen 2.5-0.5B-Instruct | Prompt Engineering |
| Stable Diffusion v1.5 | Image Generation |
| Gradio | Web Interface |
| Kaggle GPU T4 x2 | Computing |
| CLIP Score | Image Evaluation |

## 📋 How to Run
1. Open `improved_solution.ipynb` on Kaggle
2. Enable GPU T4 x2
3. Enable Internet
4. Click Run All

## 📁 Files
- `improved_solution.ipynb` - Main notebook
- `product_descriptions.csv` - Input data (15 products)
